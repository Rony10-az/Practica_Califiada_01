# Practica Calificada 01 - Semana 04 (Docker)

**Alumno:** Rony Jhostin Quintana Llanque

Este repositorio contiene dos casos prácticos de contenedorización con Docker. Cada uno tiene
su **propio README** con la explicación completa: estructura del proyecto, instalación y ejecución
en local, cómo construir y etiquetar cada imagen, cómo correr el contenedor, y la comparación entre
las 3 variantes de Dockerfile (básico, optimizado y multistage).

## Casos

- **[Caso1](./Caso1/README.md)** — Descargador de videos (YouTube, Instagram, TikTok, Facebook,
  LinkedIn) hecho en Flask + `yt-dlp`.
- **[Caso2](./Caso2/README.md)** — Registro de miembros de mesa (ONPE) hecho en Flask + `openpyxl`,
  con extracción automática del resultado de la consulta de ONPE.

Entra al README de cada caso para los detalles de esa aplicación específica.
